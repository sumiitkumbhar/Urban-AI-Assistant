# inference, not training/eval/webui, so gradio, tensorboard, deepspeed,
# tensorrt-cu12* are dropped. vllm is NOT needed either: cosyvoice/llm/llm.py
# only imports it lazily inside a function, guarded by hasattr(self, 'vllm'),

# modules via hyperpyyaml !name:/!new: tags - hyperpyyaml eagerly imports
# every module referenced there while parsing the config, even ones
# CosyVoice2 itself never calls at inference time:

#     template boilerplate, same pattern as hydra/lightning/rich below)
#   - pyarrow: cosyvoice/dataset/processor.py (parquet training-data reader)
#   - tiktoken: cosyvoice/tokenizer/tokenizer.py (via get_qwen_tokenizer)
#   - scipy: matcha/utils/audio.py (scipy.io.wavfile) and
#     cosyvoice/hifigan/generator.py (scipy.signal.get_window)
#   - einops: cosyvoice/flow/flow.py and related flow/hifigan modules
